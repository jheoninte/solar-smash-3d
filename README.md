# Solar Smash 3D

Continuation-ready HTML5 sandbox extracted from a Vertex AI planning session.

## Included
- `web-prototype/index.html`: click-to-destroy prototype
- `docs/GAME_DESIGN_SPEC.md`: core loop summary
- `docs/PROGRESSION_PLAN.md`: HTML5 to commercial roadmap
- `AGENTS.md`, `CLAUDE.md`: handoff guidance for another coding agent

## Core Features
- Planet destruction with crater feedback
- `Planet Mode` and `Solar Mode`
- `Meteor`, `Laser`, `Missile` weapon hooks
- lightweight save and audio feedback
