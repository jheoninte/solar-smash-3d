# 보류 후보: 챌린지 밸런스와 외형 수집 목표

사용자의 스마트폰 조작 개선 요청에 따라 자동공격 UX를 우선한다. 기본 자동공격과 수집 목표 UI는 구현했으며 다음 Gemini 범위는 `GEMINI_MOBILE_EXPERIENCE_PROMPT.md`다. 아래 챌린지 간격·수치는 현재 자동공격과 별도 후보이므로 그대로 덮어쓰지 말고 추후 재검토한다.

## 상태와 근거

이번 단계는 계산 검토와 Gemini 구현 지시 준비다. 게임 런타임에는 아직 적용하지 않았다. 수치 원본은 `BALANCE_CANDIDATE.json`, 재계산 결과는 `BALANCE_AUDIT.md`다. 기존 구현 검증에서 미사일 미션 m3는 0.88초에도 완료됐지만 이는 자동화 QA 기록이며 일반 사용자 평균이 아니다.

현재 무기에는 발사 간격이 없고 m3는 미사일 2발, m4는 4발, m6는 8발로 끝난다. 따라서 제한 없이 탭하는 횟수를 피해량으로 바꾼 목표만으로는 무기 선택이나 재도전 전략이 약하다. 기존 콘텐츠를 모두 완료하면 1,650코인으로 외형 전체 1,350코인을 구입할 수 있어 후속 수집 목표도 없다.

## 구현 범위

- 기존 m1~m6는 짧은 입문 콘텐츠로 유지한다. ID·목표·보상·별점 기준·발사 규칙·기존 최고기록을 변경하지 않는다. 기존 외형 ID·가격·소유 상태도 유지한다.
- m7~m12를 추가하고 챌린지에서만 `challenge-v1` 발사 간격을 적용한다. 운석 700ms, 레이저 450ms, 미사일 1,100ms이며 피해량·비행 속도·파괴 크기는 기존 값을 유지한다. 샌드박스는 자유 발사를 유지한다.
- 발사 대기는 현재 무기만이 아니라 모든 무기에 공유한다. 운석을 발사하고 다른 무기로 바꿔도 해당 운석의 남은 대기를 우회하지 못한다. 무기별 차이는 운석의 발사당 피해·중간 간격, 레이저의 즉시 명중·빠른 간격, 미사일의 큰 파괴 범위·긴 간격에서 제공한다. 실제 밸런스는 구현 후 확인한다.
- 챌린지 목표는 후보 JSON을 따른다. m11은 안쪽 작은 행성과 바깥 큰 행성 각각 미사일 15회이며 태양은 제외한다. m12는 운석 12회·레이저 18회·미사일 10회를 모두 달성해야 한다. 혼합 목표의 일부만 달성하거나 한 천체만 반복 타격해서 완료되면 안 된다.
- 신규 외형 3개는 기존 절차적 팔레트 방식으로 추가한다. 빙하 700코인, 황금 사막 900코인, 성운 1,100코인이다. 외부 이미지나 새 SDK를 도입하지 않는다.
- 신규 첫 완료 보상은 총 2,400코인이다. 기존과 합친 4,050코인으로 전체 외형 가격 4,050코인을 광고 없이 지불할 수 있다. 반복 완료는 여전히 0코인이며 별점 코인·상점 잠금·소비 재화·유료 건너뛰기는 추가하지 않는다.

## 시계·저장·UI

발사 대기는 미션 활성 시간으로 계산한다. 설정·안내·광고·동의·구매·백그라운드 동안 충전되지 않으며 재개 시 남은 대기를 유지한다. 유효한 타깃에 실제 발사했을 때만 대기를 시작한다. 거부된 입력으로 소리·파괴·보상·발사체·저장 쓰기가 생기면 안 된다. 첫 발사는 즉시 가능하고 재도전은 새 런이다. 레이저의 동기 impact 순서를 보존한다.

복합 목표의 카운터와 발사 대기는 런타임 전용이다. 기존 v6 저장 구조에 새 미션 ID와 외형 ID를 추가하는 방식으로 진행한다. m1~m6 기록을 초기화하거나 새 기준으로 재해석하지 않는다. 실제 저장 구조 변경이 필요하다면 구현 전에 이유와 이전 방법을 보고하되, 이번 설계는 버전 변경을 필요로 하지 않는다.

목록은 입문/챌린지를 구분하되 모두 선택 가능하게 한다. 진행 HUD에는 m11의 두 천체별 진척, m12의 세 무기별 진척, 챌린지의 재사용 대기를 표시한다. 천체는 색상만으로 구분하지 않는다. 결과는 기존 기록·보상·광고 흐름을 유지한다. 320px 화면에서 복합 목표가 게임 화면을 지나치게 가리지 않는지 확인한다.

## 완료 기준과 다음 검증

1. 기존 40개 테스트 유지 및 발사 간격 경계·무기 교체 우회·정지/재개·재도전·구형 미션/샌드박스 보존 테스트 추가.
2. 복합 목표의 각 조건, 잘못된 무기·천체·이전 런, 완료 1회 처리, 신규 기록 복원과 기존 기록·코인·보너스 원장·외형 보존 검증.
3. 광고 없이 모든 외형 구매 가능, 신규 보상 1회, 반복 보상 0과 광고 보너스 원장 중복 방지 확인.
4. 계산상 최소 시간과 실제 브라우저 완료 시간을 구분해 보고. m7~m12의 30~90초 체험은 목표이며 보장이나 실측 결과가 아니다. 조준·무기 전환의 재미 없이 반복 탭만 늘었다면 후속 플레이테스트에서 목표량과 구성부터 다시 조정한다.
5. SDK/실서비스 ID·Firebase·Game Center·분석 도구·자동 광고 정책을 변경하지 않는다. Mac 네이티브 검증은 이후 단계다.
