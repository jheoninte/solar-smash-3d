# 미션 재도전 1차: 별점과 로컬 최고기록

## 목적과 현재 상태

구매·광고 공통 흐름과 iOS 브리지 소스 검토 이후, 다시 플레이할 목표를 보강했다. 기존 6개 미션의 완주 별점과 최고기록을 구현·통합했고 Windows 자동 테스트와 브라우저 QA를 완료했다. iPhone 동작·밸런스·리텐션 효과는 아직 검증하지 않았다.

첫 완료 코인 합계는 1,650이고 반복 완료 보상은 0이다. 별점 보상·반복 코인·해금 제한을 추가하지 않는다. 광고 보너스는 기존 첫 완료 저장 성공 이후 1회 정책을 유지한다. 기록 갱신만으로 광고 보너스 기회를 다시 만들지 않는다.

## 평가 규칙

- 목표를 달성하면 최소 별 1개다. 제한 시간 초과로 실패시키지 않는다.
- 미션별 3성 기준 이하이면 별 3개, 2성 기준 이하이면 별 2개, 그 외에는 별 1개다. 경계값을 포함한다.
- 시간은 해당 런에서 실제로 플레이한 시간이다. 미션 시작부터 목표 달성까지이며, 발사체 비행과 카메라 조작은 포함한다. 설정·안내·다른 모달·광고/결제/동의 화면·백그라운드 대기는 제외한다.
- `performance.now()`처럼 단조 증가하는 주입 가능한 시계를 쓴다. 렌더링 delta의 50ms clamp 누적으로 시간을 계산하지 않는다. 프레임 저하가 기록상 이득이 되면 안 된다. 기기 날짜·시간대와 무관하게 동작한다.
- 완료 시 시간을 고정한다. 완료 후 모달 열기, 애니메이션, 저장·광고 대기가 기록을 바꾸지 않는다. 재도전·새 미션은 새 런이며 종료한 런의 지연 impact는 무시한다.

초기 기준은 밸런스 플레이테스트 전 임시값이며 난이도·리텐션 실측 결과가 아니다.

## 저장과 UI

- 저장 스키마 v6: `progression.missionRecords[missionId] = { bestActiveMs }`. 평가 규칙은 미션 정의에 두고 별은 기록에서 계산한다. 중복 별점 필드를 저장하지 않는다.
- 기존 키와 코인·완료 미션·광고 보너스 원장·외형·지형을 보존한다. v2/v3/v4/v5는 기록 없는 상태로 이전한다. 과거 완료 데이터에서 시간을 추정하거나 보상을 재지급하지 않는다.
- 알 수 없는 미션 ID, 배열/비객체 기록, 음수·0·비유한·안전 범위 밖 시간은 정규화 과정에서 제거한다. 정상 저장 전체를 초기화하지 않는다. 손상 JSON·미래 버전의 쓰기 차단과 순차 스냅샷 저장은 유지한다.
- 완료 목록을 기준으로 v6의 기록만 복원한다. 미완료 미션에 잘못 들어간 기록은 첫 완료 보상을 소모하지 않는다. 과거 버전에 우연히 포함된 기록 필드는 무시한다.
- 결과에는 이번 별점·시간, 이전 최고기록과 기록 갱신 여부, 다음 별의 시간 목표를 표시한다. 느린 재도전은 기존 최고기록을 낮추지 않는다. 동률은 갱신이 아니다.
- 미션 목록에는 최고 별점·최고시간을 표시한다. 기존 완료인데 측정 기록이 없다면 '완료 · 기록 없음'으로 표시한다. HUD는 진행도와 읽기 쉬운 시간을 표시하되 매 프레임 DOM 전체를 재생성하지 않는다.
- 3성 완료 후에는 최고시간 단축을 목표로 안내한다. 별만으로 상태를 전달하지 않고 텍스트와 접근 가능한 레이블을 제공한다. 320px 폭과 safe area를 고려한다.

## 범위와 후속 판단

Gemini 초안을 Codex가 검토·보완·통합했다. 네이티브 SDK·수익화 정책·설정 저장 키·무기 밸런스·콘텐츠 수는 유지했다.

로컬 기록이 재도전 동기를 만드는지 먼저 확인한다. 이번 단계에는 Game Center·Firebase·분석 SDK·서버·일일 접속 보상을 추가하지 않는다. Game Center는 점수 규칙과 경쟁 수요가 확인될 때 별도 단계로 결정한다. Mac 조기 전환을 선행 조건으로 삼지 않는다.

## 검증 결과 (2026-11-17)

- 전체 Node 테스트 40개 통과. 별점 경계, 정지 사유 중첩, 완료 시간 고정, 이전 런 차단, 즉시 레이저 완료, 느린/동률 재도전, 보상·보너스 중복 방지, v2~v5 이전과 v6 기록 정규화를 검증했다.
- Preferences 주입 테스트에서 첫 쓰기를 실제 Promise로 지연시키고 다음 기록 갱신을 요청했다. 동시 쓰기 최대 1개와 기존/개선 기록 스냅샷 순서를 확인했다. 실제 iPhone Preferences 실행을 의미하지 않는다.
- 저장소 검사·웹 빌드·native:prepare 통과. 네이티브 준비 검사는 Swift 컴파일이나 SDK 실행 검증이 아니다.
- 브라우저에서 미사일 완주 3성·첫 보상 200코인, 빠른 재도전의 기록 개선·추가 코인 0, 새로고침 후 최고기록 복원을 확인했다. 설정→조작 안내→설정 전환 동안 타이머 4.03초가 유지됐다. 레이저 10회 즉시 타격 완주도 확인했다.
- 320×740 CSS px에서 결과창이 화면 안에 들어가고 미션 목록에 가로 넘침이 없었다. 콘솔 warning/error는 없었다. 브라우저 결과는 iPhone 터치·네이티브 수명주기·성능 검증과 구분한다.
