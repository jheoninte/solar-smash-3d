# Game Design Spec

## Genre
- 3D planet destruction sandbox
- instant visual payoff and weapon experimentation
- Free-to-play hybrid casual, iOS first, Android later

## Core Loop
1. choose mode and weapon
2. strike a planet or orbit target
3. observe crater, heat, debris and audio
4. repeat with stronger tools

## MVP
- 2 modes
- 3 weapons
- crater feedback
- save and audio toggle

## Release Loop
- Keep free sandbox experimentation alongside short data-driven missions.
- Mission completion grants local progression rewards exactly once.
- Monetization candidates: remove-forced-ads and cosmetic IAP, optional rewarded ads, interstitials only at natural breaks.
- Offline core, no custom server. Optional Game Center for defined challenge scores and achievements.
- See `RELEASE_PLAN.md` for platform validation, monetization and release gates.
