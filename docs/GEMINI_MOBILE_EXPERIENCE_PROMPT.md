# Gemini 구현 요청: 자동공격의 손맛과 장시간 성능

첨부한 최신 실제 파일을 기준으로 구현해주세요. Windows에서 Codex와 개발하고 최종 iOS 빌드·실기기·TestFlight는 Mac mini에서 진행합니다. 대규모 구현은 Gemini, 검토·통합·검증은 Codex가 담당합니다.

## 이전 응답을 바로잡는 지시

직전 응답은 보류한 m7~m12·Glacier/Dune/Nebula 확장을 구현하여 이번 요청과 달랐습니다. 그 응답은 통합하지 않았습니다. 아래 첨부된 현재 정상 소스를 기준으로 **이번 구현 범위 1~3만** 작업하세요. 이전 챌린지 코드를 수정해서 다시 제출하는 작업이 아닙니다.

이전 응답의 전 모드 manualFire 적용은 샌드박스/m1~m6 수동 공격 규칙을 변경했고, 절대 시계 기반 대기는 정지 중에도 소모됐으며, 발사 콜백의 stop 후 명시적 재시작 테스트도 실패했습니다. 현재 자동공격 계약과 기존 45개 테스트를 유지하세요. 기존 정상 소스의 과제만 수행하므로 그 실패 코드를 다시 도입할 필요가 없습니다. 응답 첫 줄에 이번 세 과제인 '연속 레이저 연출 / 최근 120타격 성능 / 모바일·Solar 조준'을 적어 작업 범위를 확인해주세요.

## 이미 구현된 동작 — 보존

- 사용자가 확정한 기본 조작은 **자동공격 버튼으로 켜기/끄기**입니다. 반복 탭이나 길게 누르기를 기본으로 바꾸지 마세요.
- AutoFireController가 운석 700ms, 레이저 450ms, 미사일 1100ms 간격으로 발사하며 한 프레임에 밀린 공격을 몰아 쏘지 않습니다. 수동 탭·드래그 회전·핀치/휠은 유지됩니다.
- 조준점은 HUD와 무기 패널 사이에 있습니다. 미션 완료·메뉴·blur·백그라운드·Reset·모드 전환에서 꺼지며 자동으로 재시작하지 않습니다.
- 상점/결과창의 다음 외형 목표와 부족 코인 안내, v6 저장·최고기록·중복 보상 방지, SDK 경계는 유지합니다.
- docs/BALANCE_PLAN.md의 챌린지 추가는 보류입니다. 이번 작업에서 미션/가격/보상/저장 스키마를 확장하지 마세요.

## 이번 구현 범위

1. **연속 레이저 시각 효과**: 자동 레이저가 동작하는 동안 가느다란 빔·접점 발광이 이어지게 하세요. 실제 데미지/impact는 기존 450ms cadence만 따릅니다. 매 프레임 데미지를 추가하지 않습니다. 빈 공간·가려진 표적·모드 전환·미션 완료·설정·숨김·무기 변경 시 잔상이 남지 않게 정리합니다. WeaponSystem/렌더 계층에서 처리하고 플랫폼 SDK는 건드리지 마세요.
2. **120개 rolling impact 성능**: BodyMode.onImpact는 이력이 가득 차면 지형 reset 후 최대 120타격을 매번 재생합니다. 최근 120개만 보존하는 동일한 저장/복원 결과, 이음새·색상·법선·열 상태를 유지하면서 반복 비용을 줄이세요. 오래된 크레이터가 계속 남는 방식은 금지합니다. 첫/120번째/121번째/300번째 타격, 모드 혼합, 재장착, 재시작 복원과 시각 일치성을 검증하고 CPU 시간 측정 스크립트 또는 재현 가능한 계측을 제공하세요. 메모리 상한과 dispose도 설명하세요.
3. **작은 화면 조준**: 320×740 세로, 740×320 가로에서 중요 HUD/44px 이상 조작 버튼과 행성을 충분히 보이게 하세요. Solar의 작은 행성을 자동공격으로 겨냥하기 어려운 점을 개선하세요. 사용자 탭으로 조준점을 옮기는 등 작은 입력 확장을 택하되 드래그/핀치와 충돌하지 않게 하고 조준 표시와 실제 Raycast가 일치해야 합니다. 보이지 않는 표적에 자동 명중시키지 마세요.

## 제외 / 검증 / 반환

- 새 엔진·서버·Firebase·결제 상품·무료 코인 버튼·가짜 광고/구매·보상 변경은 제외합니다. 연출과 조작 개선이 매출을 보장한다고 쓰지 마세요.
- npm test, npm run check, npm run native:prepare를 유지하세요. iPhone/Swift 검증을 했다고 주장하지 마세요.
- 먼저 변경 파일과 접근 방법을 간단히 설명하고 **수정/추가한 파일만 각각 완성된 전체 코드**로 반환하세요. 코드 생략·diff만 반환·구버전 네이티브 파일 덮어쓰기는 금지합니다. 확인하지 못한 부분은 명시하세요.
